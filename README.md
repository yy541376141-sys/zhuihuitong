# 智会通 · AI 智能会议工作台 (ZhuiHuiTong)

> 新一代企业级 AI 会议助手，支持实时麦克风收音、音频文件拖拽导入、星辰多角色说话人分离转写与 DeepSeek 场景化结构化纪要提炼。

## ✨ 核心特性

- 🎙️ **多源音频输入**：支持麦克风实时高保真录音、本地文件导入、直接将音频文件拖拽至窗口任意位置。
- 👥 **星辰多角色分离 (Speaker Diarization)**：自动识别多位参会发言人身份并生成精准时间轴。
- 📝 **场景化结构化纪要**：内置投资评审、周例会、商务谈判等多种专业场景模板，一键提炼背景、核心决议、行动项与风险分析。
- 📋 **行动项看板与日历导出**：支持任务勾选、责任人分派，一键导出 `.ics` 日历文件及工作群沟通文本。
- 🎨 **Apple 现代设计语言**：Bento Grid 响应式栅格布局、毛玻璃材质与声谱动效，支持深浅色无缝自适应。
